#+Title: Prototype duolinguo-style gamified exam
#+author: [[mailto:mrenzo@arizona.edu][Mathieu Renzo]]

Prototyped with Claude Sonnet 4.5

Answers are auto-generated for playground and may be incorrect.
Aims at being platform agnostic.

* Development

Clone this repo and get into it:

#+BEGIN_SRC bash
  git clone git@github.com:mathren/gamified_exam.git && cd gamified_exam
#+END_SRC

Create with conda or mamba an environment and activate it:

#+BEGIN_SRC bash
  conda env create --name gamified_exam -f requirements.txt
  conda activate gamified_exam
#+END_SRC

Install with pip the requirements:

#+BEGIN_SRC bash
pip install -e ".[dev]"
#+END_SRC

and verify installation:

#+BEGIN_SRC bash
python -c "from gamified_exam import GamifiedExam; print('Success!')"
#+END_SRC

You can use =notebooks/dev.ipynb= to load functions and experiment with
them, or run =python exam.py= in your terminal for the full test run.

** Example

In an iPython session:
#+BEGIN_SRC python
  from gamified_exam import GamifiedExam
  exam = GamifiedExam("data/exam_questions.txt")
  exam.run_exam()
#+END_SRC
